### GitHub Project Description

**ISO 27001 Lab – Active Directory & Group Policy**

This repository contains a Windows Server 2022 Active Directory lab created as part of a **recruitment task**. The project demonstrates the deployment of an Active Directory Domain Controller, creation of organizational units and standard users, and implementation of Group Policy Objects (GPOs) to restrict user access to specific applications while maintaining normal system functionality.

**Note:** This repository was developed **exclusively for the recruitment task provided by the hiring company** and is intended solely to demonstrate my technical knowledge, practical skills, and approach to system administration and Active Directory management. It is not intended for commercial use or production deployment.
